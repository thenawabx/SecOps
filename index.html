# NawabHunter-Ultimate

NOTE: Automation recon script for authorized testing only.

## Disclaimer

Use this tool only on assets you own or have written permission to assess.

## Download and setup

1. Click "Download complete scanner (.zip)" above and save `NawabHunter-Ultimate-main.zip` in Downloads.

2. Open a Kali or NetHunter terminal and extract the project:

cd ~/Downloads
unzip NawabHunter-Ultimate-main.zip
cd NawabHunter-Ultimate-main

3. Install the required Python packages:

python3 -m pip install -r requirements.txt

4. Install the required reconnaissance tools listed in the bundled README. The scanner uses Go, Nmap, httpx-toolkit, Assetfinder, Katana, Nuclei, Subfinder, DNSx, Waybackurls, and Mantra.

Copy and run this one-liner in order. The -y flag is used only for apt commands because Go and shell commands do not support it.

sudo apt update --fix-missing -y && sudo apt install -y golang python3 git python3-pip curl pv jq traceroute nmap httpx-toolkit assetfinder && GOSUMDB=off go install github.com/projectdiscovery/katana/cmd/katana@latest && GOSUMDB=off go install github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest && GOSUMDB=off go install github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest && GOSUMDB=off go install github.com/projectdiscovery/dnsx/cmd/dnsx@latest && GOSUMDB=off go install github.com/tomnomnom/waybackurls@latest && GOSUMDB=off go install github.com/brosck/mantra@latest && printf '\nexport PATH="$PATH:$HOME/go/bin"\n' >> ~/.bashrc && printf '\nexport PATH="$PATH:$HOME/go/bin"\n' >> ~/.zshrc && export PATH="$PATH:$HOME/go/bin"

5. Start the scanner:

chmod +x scanner.py
python3 scanner.py

6. Follow the terminal prompts. Choose wildcard or domain mode, choose the tool set, and enter only an authorized target.

## Optional shortcut
source ~/.bashrc
runawab
## Results

Wildcard scans use one recon_wildcard_example_com folder. Subdomain artifacts are stored together with a combined Vulnerability_Report.txt. Single-domain scans are stored in recon_single_targets.

## Features

- Raw tool output and progress display.
- Ctrl+C skips the current step; a quick second press exits.
- Custom Nuclei templates are included in Nuclei_Templates.
- Scanner templates are loaded relative to scanner.py.
